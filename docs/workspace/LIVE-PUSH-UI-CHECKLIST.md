# Phase 3 visual validation checklist

- Desktop: live/offline cards, audience chart, goals, recent sessions, comparison, notification list/preferences.
- Mobile 320/390px: thumbnail, viewers, duration and CTAs remain readable; analytics scroll; preference controls are touch-friendly.
- Twitch connect: invalid host, username resolution, explicit identity confirmation, provider unavailable state.
- PWA: install from Workspace manifest, service-worker scope, enable/disable/test push, multi-device and iOS Home Screen help.
- EventSub: challenge, online/offline freshness and no duplicate card/session/notification.
- Roles: Manager cannot manage accounts/goals; Player cannot access Live Center globally; users only see their push devices.

No browser executable was available in the delivery container; this checklist is intentionally not marked complete.
