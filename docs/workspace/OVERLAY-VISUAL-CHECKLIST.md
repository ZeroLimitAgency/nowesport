# Overlay visual checklist

- [ ] Editor at desktop width: layers, 16:9 canvas, inspector and history.
- [ ] Management actions remain usable at mobile width.
- [ ] Renderer at 1920×1080 in OBS Chromium.
- [ ] Runtime text changes within configured refresh interval.
- [ ] Invalid/revoked token produces a neutral transparent response.
- [ ] Image/video assets and fade/slide/pulse presets.
