# Personnalisation

Changer le branding dans le shell et `src/workspace/now`. Les noms de rôles sont des données `workspace_roles`; seules les permissions pilotent l'accès. Pour une organisation, insérer `organizations`, sa hiérarchie `departments`, ses rôles/grants puis les membres. Pour un jeu, ajouter un département, un module sous `games/<slug>` et des permissions/routes; Fortnite n'est pas une contrainte du core.
